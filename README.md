# Finance Sandbox Pro

A responsive, dark FinTech portfolio landing page built with React, Vite, Tailwind CSS and Lucide React.

## Getting started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/App.jsx` — page layout, case studies, download actions and toast feedback
- `src/index.css` — responsive dark FinTech design system and component styles
- `public/data/` — downloadable illustrative case-study datasets
- `public/templates/` — Excel-compatible CSV spreadsheet templates

## Deploy

Import this repository into Vercel or Netlify. Use the default Vite settings:
- Build command: `npm run build`
- Output directory: `dist`

## Data disclaimer

All financial figures and assumptions included in the sample CSV files are illustrative educational inputs. They are not investment advice, audited data, or official market forecasts. Replace and validate assumptions against primary sources before using them in professional analysis.
